Copy this folder into mods to test a new BRZ wing entry. It reuses the stock wing model and an existing localized street-wing name, costs 101 CR, and uses sample part ID 1655099 / level 5. It demonstrates how database.json and a carbin patch work together; no model assets are included or required. Replace the model path and provide your own model for a real new wing. See CARBIN.md in the release root. Restart after installing/removing it. Do not reuse this sample ID in released packs.
