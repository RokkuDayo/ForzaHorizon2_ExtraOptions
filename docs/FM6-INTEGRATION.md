# FM6 integration candidate 2

Based on the supplied global snapshot and standalone Pre7. The global winmm proxy dispatches FM6 only to a companion C++ DLL, using the native mapper handoff. This avoids mixing the global freestanding C linker with C++ runtime code. It is one distribution, not one binary. No standalone proxy or launcher hooks are included. Existing FH2/FH3/FM5 paths remain unchanged. FM6 includes camera/blur/HUD features and Victor Alves’ checked SkipIntro, SkipPresentationVideo and UnlockDLC patches. UnlockDLC overrides ownership checks, does not install content, and defaults off; use only with owned content. VIP, font, wheels and menu FPS are not ported. The three new switches are startup-only. Accept/Cancel/Reset still use immediate save behavior. No game assets are changed on disk.

Use GitHub Actions Build. Extract package into a clean Azimuth directory after backing up old DLLs and INIs. Do not run the standalone winmm or another Extra Options loader simultaneously. Copy old [FM6] camera settings into FM6_ExtraOptions.ini if desired. Open HUD Options; exercise all controls, restart and check persistence. Send FM6_ExtraOptions.log. Test other titles individually for regressions. RC1 Hotfix 2 was reported compiled and working in-game by the user. RC2 requires a fresh Windows build and runtime test.
